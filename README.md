# FÊTE

세계의 축제를 손으로 만지는 곳. 축제마다 그 축제로 만든 작은 세계가 있어요.

## 열려 있는 축제
| 축제 | 재료 | 하는 법 |
|---|---|---|
| 이펭 등불축제 (태국 치앙마이) | 종이와 나무, 안에서 나오는 불빛 | 화면을 누르면 등불이 떠요. 소원을 적어도 돼요. |
| 죽은 자의 날 (멕시코) | 설탕 반죽과 진짜 금잔화 | 화면을 누르면 촛불이 켜져요. 이름을 적어도 돼요. |
| 라 토마티나 (스페인 부뇰) | 방울토마토 인물과 소금빛 건물 | 화면을 눌러 토마토를 던져요. |

곧 열려요: 버닝맨(골판지와 철사), 홀리(색분필 가루), 송끄란(유리와 물방울)

## 쓰는 법
- 위로 쓸면 다음 축제, 아래로 쓸면 이전 축제
- 오른쪽 위 "뽑기"로 오늘의 축제 뽑기

## 파일 구조
```
index.html        화면 뼈대
css/style.css     디자인 (폰트: Jua, Gowun Dodum, Fraunces)
js/data.js        축제 이미지 경로
js/core.js        축제 정보, 소리, 스와이프, 화면 전환
js/scenes.js      축제별 터치 효과 (등불, 촛불, 토마토)
js/gacha.js       캡슐 뽑기
img/              축제 이미지
  yi-peng.jpg, dia-de-muertos.jpg, la-tomatina.jpg
```

## 새 축제 추가하는 법
1. `img/`에 이미지를 넣어요. (예: `holi.jpg`)
2. `js/data.js`의 `IMG`에 경로를 추가해요.
3. `js/core.js`의 `FEST`에서 해당 축제의 `locked:1`을 지우고 `fact`, `ph`, `btn`, `unit`을 채워요.
4. `js/scenes.js`에 `SC.holi=()=>{...}` 형태로 터치 효과를 만들어요.
